# Security policy

## Supported versions

Security fixes are released for the latest minor version of the current major version. Before 1.0, only the latest 0.x release receives fixes.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues.

Report them privately through [GitHub private vulnerability reporting](https://github.com/rkistaps/the-app/security/advisories/new). Include:
- the affected version
- steps to reproduce, or a proof of concept
- the impact you expect

You'll get a reply within 7 days. Once a fix is released, the vulnerability is disclosed in a GitHub security advisory, with credit to you unless you'd rather stay anonymous.
